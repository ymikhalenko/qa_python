- test_add_new_book_new_books_doesnt_have_genre() - новая книга не имеет жанра

- test_set_book_genre_add_four_books_with_genres() - жанры указываются и возвращаются
- test_get_book_genre_comedy_book_returns_comedy_genre() - по книге возвращается верный жиани
- test_get_books_with_specific_genre_comdey_genre_returns_two_books() - книги с определенным жанром возвращаются
- test_get_books_for_children_returns_two_books() - возвращается верное кол-во детских книг

- test_add_book_in_favorites_add_two_books() - книги добавляются в избранное и возвращаются
